二、新增设置项「金额计价」（costMode）

CC Switch 库里的 total_cost_usd 名义是美元，但它界面按 1 美元 = 5 元折算显示。
提供三种模式，让用户按自己中转站的实际计价方式选：

- internal（默认）÷5，与 CC Switch 界面数字一致
- real     ×7.2 真实汇率，适合按真实美元结算的中转站
- raw      不换算，原样显示库里的值（标 $）

改动落在：
- config.js          新增 costMode 默认值 internal
- ccswitch.js        新增 COST_MODE / toDisplay / unitOf，readTodayCost 与
                     readTodayCostBy 接受 mode 参数并返回 unit / mode
- settings.html      新增「金额计价」小节下拉框
- settings.js        填充与读取 costMode
- worker.js          把 cfg.costMode 传给 readTodayCost
- main.js            pushData 时把最新 config 一起发给 worker

三、修复三个相互叠加的隐蔽 bug（设置页改动不生效）

排查过程发现三层问题叠在一起，每一层单独看都不像 Bug：

1. TDZ：readTodayCost(cfg.costMode) 写在 const cfg 声明之前，
   抛 Cannot access cfg before initialization，被 try/catch 吞掉，
   花费数据静默变成 ok:false
2. 签名不匹配：调用处写 runOnce(msg.config)，函数签名却还是 runOnce()，
   参数被丢弃，cfg 恒为 undefined
3. 形参遮蔽：函数体内又写了 const cfg = config.load()，把形参盖掉；
   而 config.load() 有模块级缓存，worker 进程内只读一次文件，
   于是设置页保存的新值在 worker 里永远看不到

三者叠加的结果：UI 显示已保存、config.json 也写对了，但运行时纹丝不动。
