# README 配图清单

图片统一放在仓库根目录的 `.assets/`，README 用相对路径引用：

```markdown
![描述](.assets/01-xxx.png)
```

你按下面的编号命名并放进去，我来把引用写进 README。

---

## 01 — 整体外观（最重要，决定第一印象）

- **文件名**：`.assets/01-overview.png`
- **放哪**：README 开头，紧跟项目简介那段
- **画面**：屏幕顶部居中的悬浮条处于**展开态**
  - 三个环（绿 / 橙 / 蓝）并排，环内各有品牌图标
  - 今日金额数字（如 `￥2.32`）
  - `☰` `⟳` `⚙` `⊖` `✕` 按钮
  - 下方详情面板展开，露出「全部模型（24H 调用量）」列表
- **怎么截**：
  1. 启动 AgentHUD
  2. 鼠标移到悬浮条上，等它"活起来"露出按钮
  3. 点 `☰` 展开详情面板
  4. `Win + Shift + S` 框选屏幕顶部这一块
- **注意**：桌面用深色或干净壁纸；别截到私人文件 / 浏览器标签
- **建议尺寸**：宽 1200~1600px，能看清文字就行

---

## 02 — 圆环特写（解释「圆环在表达什么」）

- **文件名**：`.assets/02-rings.png`
- **放哪**：README「圆环在表达什么」小节
- **画面**：**只截悬浮条本身**（不展开面板），放大到能看清
  - 三个环并排，环内品牌图标清晰
  - 至少一个环带明显的进度弧（今天有花费时才会出现）
  - 能看出颜色差异（绿=可用 / 红=限流中 / 灰=无调用）
- **怎么截**：鼠标移到悬浮条上 → `Win + Shift + S` 只框选那一小条 → 若原图太小，用画图放大 2 倍再存 PNG
- **注意**：如果三个环颜色都一样（都绿），说明没限流也没花费，可以在文案里说明

---

## 03 — 侧边停靠（竖排形态）

- **文件名**：`.assets/03-side-dock.png`
- **放哪**：README「交互」小节
- **画面**：屏幕左侧的竖排胶囊
  - 鼠标悬停后露出 `☰` `⚙` 按钮
  - 右侧展开的详情面板
- **怎么截**：
  1. 设置 → 停靠位置改为「屏幕左侧（竖排）」→ 保存
  2. 鼠标移到左侧竖条上 → 点 `☰` 展开
  3. 截图
- **注意**：截完记得把停靠位置改回你常用的

---

## 04 — 详情面板（模型用量 / 限流 / 最近会话）

- **文件名**：`.assets/04-panel.png`
- **放哪**：README「交互」小节，紧随 03 之后
- **画面**：完整详情面板，尽量涵盖三个分区
  - 全部模型（24H 调用量）列表 + 用量条
  - 限流区（若开着 Beta 且有限流记录）
  - 最近会话
- **怎么截**：点 `☰` 展开后，`Win + Shift + S` 只框面板（不含悬浮条）
- **注意**：如果面板内容多要滚动，可分两张（04a 上半 / 04b 下半），我在 README 里并排放

---

## 05 — 设置窗口

- **文件名**：`.assets/05-settings.png`
- **放哪**：README「设置」相关小节
- **画面**：完整设置窗口，七个分组都可见（按新顺序）：
  1. 常规
  2. 悬浮条圆环
  3. 监控数据源
  4. 采集
  5. Codex 中转站余额
  6. 金额计价
  7. **Beta** 限流监控（金色标签）
- **怎么截**：点悬浮条上的 `⚙` → 截图整个窗口
- **⚠️ 安全**：截图前**清空「凭据（Token 或 Cookie）」输入框**，
  也不要截到「站点地址」里的真实域名 —— 那是你的私密信息
